# Ragdoll Punch

YouTube Playables 검토용 빌드를 GitHub Pages 로 호스팅하는 레포입니다.

- 안내 페이지: https://cookapps-creative.github.io/RagdollPunch/
- Unity WebGL (YouTube 공식 템플릿): https://cookapps-creative.github.io/RagdollPunch/webgl/index.html
- Playworks 변환 HTML: https://cookapps-creative.github.io/RagdollPunch/html/index.html

영어판 확인: 주소 끝에 `?lang=en` (유튜브 안에서는 SDK 언어 설정을 따릅니다).

## 들어 있는 것

| 폴더 | 내용 |
|---|---|
| `webgl/` | Unity 6 WebGL 빌드 (Brotli 압축, 서버 설정 없이 동작) |
| `html/` | Playworks(Luna) 단일 HTML |

**빌드 결과만** 올립니다. 게임 소스 프로젝트, 애니메이션 원본(FBX), 폰트 원본은 포함하지 않습니다.

## 사용한 외부 리소스

- 폰트: Noto Sans / Noto Sans KR — SIL Open Font License 1.1 (게임에 쓰는 글자만 남긴 서브셋)
- 일부 춤 동작: Adobe Mixamo 애니메이션을 뼈 방향 데이터로 변환해 사용 (원본 파일은 포함하지 않음)
- YouTube Playables SDK / Google YTGame Wrapper 템플릿 — Apache License 2.0
